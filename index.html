    Amie desktop app¶

    Amie is a desktop workbench for small intent models. You write a Kotlin script in the sandbox, it trains a classifier on top of a BERT encoder, the result lands in the AMP/ folder next to the app, and from there you can read its metrics, draw them as charts in the console, serve the model over HTTP, and open package jars from the Amie server. Devices connected to the Amie backend have a dashboard (not reachable from the sidebar at the moment; see Devices).

    This site is plain Markdown in the repository's docs/ folder, built with MkDocs (mkdocs.yml at the repository root). Read it on GitHub, or serve it:

    mkdocs serve -a 127.0.0.1:8000      # live-reloading site at http://127.0.0.1:8000
mkdocs build                        # static site in build/docs-site/

    The app in one minute¶

    1. Run ./gradlew :desktopApp:run. No account is needed: the app opens on the sandbox (signing in, under Account in Settings, only matters for publishing, backups and the package repository, see Signing in).
    2. In the sandbox, open the templates (the disk icon over the editor) and load one, or type a script, then press Run (⌘↵ / Ctrl+Enter). The dummy model is there from the start:
    val m = initMod("dummy")                              // opens a session, or returns the open one
log(m.predict("turn the lights on"))                  // lights
log(m.inference("turn the lights on").first())        // lights:0.61
    1. Open Models (second sidebar icon), Sessions tab: the session is still open, with its log and a Terminate button. How sessions behave is in Running sessions. To train your own model:
    val train = source("intents.csv")          // columns: text,label
val model = modelBuilder("intents", train)
metricsChart("intents")                    // F1 per label as bars
metricsHistory("intents")                  // accuracy and macro F1 over every build
    1. On the Models page every model is a component to configure, serve, open and publish, and every open session can be terminated there.
